## 🚀 5步將網站完全免費架設至 GitHub Pages

1. **建立 GitHub 儲存庫 (Repository)**：
   登入您的 GitHub 帳號，點擊右上角 `+` 號選擇 **New repository**。填寫儲存庫名稱（例：`organic-school-lunch-study`），並確保勾選為 **Public (公開)**，點擊下方的 Create 建立。

2. **上傳網站檔案**：
   在建立完成的空儲存庫頁面中，點擊 **"uploading an existing file"**。將您電腦中本解壓後資料夾內的所有內容（包括 `index.html`、`css/` 資料夾、`assets/` 資料夾）**全部拖拽**進瀏覽器視窗中。

3. **提交變更**：
   檔案上傳完成後，捲動到頁面最下方，點擊 **Commit changes** 按鈕保存。

4. **啟用 GitHub Pages 網頁託管**：
   - 進入該儲存庫右上角的 **Settings (設定)**。
   - 在左側選單中點擊 **Pages**。
   - 在 **Build and deployment** 下方的 Branch，將原本的 `None` 改選為 `main` (或 `master`)，後方的路徑保持 `/ (root)`，點擊右側的 **Save** 儲存。

5. **瀏覽成果發表網站**：
   稍等 1 至 2 分鐘後重新整理該 Pages 設定頁面，頂部就會出現您的專屬學術成果網址（格式如：`https://您的GitHub帳號.github.io/organic-school-lunch-study/`）。
